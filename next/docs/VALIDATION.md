## .7.2 保留的安装与官方客户端验证

以下为 2026-09-17 的历史验证，本版没有重跑这些完整客户端场景。

使用独立的公开源码副本，给原安装建立包含中文和空格的新目录联接，再从这个路径执行 setup；这是同一台电脑上的路径迁移模拟，并非朋友电脑验收。

- native / isolated 的 doctor 均通过，source 为新路径。
- 独立浏览器成功启动曹操斗地主并进入 choice；新的 CLI 进程能继续 observe。
- 后台错误监听 armed；stop 返回 cleanupComplete=true。
- 独立房间创建 Agent 房主，两个客机加入，启动后状态为 playing，最后 room close 成功。此项验证建房和选将入口，没有跑完整局。
- 使用保存的目录快捷导入最小测试 ZIP 至房间扩展库，loaded=true；未向原游戏安装测试扩展。

另以本机官方发行目录执行兼容验证：

- native doctor 自动识别 `noname.exe`，无需 `--executable`；isolated doctor 通过。
- 不启用第三方扩展时，曹操身份局成功进入并可继续观察、操作。
- 显式提供 `--extensions Nihilphile --character-packs nihilphile` 后，可选择该包实际存在的 `nihil_guanyu`；默认配置查询不到该包武将。
- 房间运行时能够复制并启动 `noname.exe`、进入联机配置页，但房间服务器初始化停在 `ready=false`。这证明文件名兼容生效，不构成官方版本地联机通过。
