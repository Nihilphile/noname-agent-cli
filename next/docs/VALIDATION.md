- native / isolated 的 doctor 均通过，source 为新路径。

另以本机官方发行目录执行兼容验证：

- native doctor 自动识别 `noname.exe`，无需 `--executable`；isolated doctor 通过。
- 不启用第三方扩展时，曹操身份局成功进入并可继续观察、操作。
