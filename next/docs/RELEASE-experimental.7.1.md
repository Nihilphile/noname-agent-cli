# 1.3.0-experimental.7.1

- 增加 setup --source，保存本机游戏安装路径，支持安装根目录、resources/app、中文和空格目录。
- 启动、建房和扩展导入复用本机配置；移除开发者安装路径默认值。可通过环境变量或显式参数覆盖。
- 浏览器自动检测使用系统环境目录，可通过 setup --browser 配置。
- 同步公开 README、安装指南和 Agent skill；公开源码与 ZIP 排除个人配置、原始实验记录和旧历史附件。
- 保留 .7 的 ZIP 快捷导入和会话后台错误报告能力。

此版本仍为 Windows 实验版，匹配的游戏本体需自行准备。验证范围见 [VALIDATION.md](VALIDATION.md)。
