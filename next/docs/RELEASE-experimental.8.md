# 1.3.0-experimental.8

人类游玩现在可以后台保存实验战报，Agent 在关窗后也能按局直接阅读文本；`play` 增加与实验日志一致的语义匹配，并改善已承诺操作链跨被动结算、他人响应时的连续执行。

- 新增 `watch on|off|status`、`logs --all`、`logs games`、`logs --game ID`，支持按轮次和事件序号筛选。默认文本，显式 `--json` 才返回结构化数据。旧操作证据中的实验事件自动合并去重，缺段明确标出。
- 新会话自动后台记录；人类通过 `watch on` 打开或连接原客户端，自行选将操作。记录器独立保存玩家可见实验事件，不消耗 `act/play` 的增量游标，玩家死亡后继续记录，停录前尝试保存末次事件。
- `play` 支持 `杀【♥12】[角色]`、`杀【id:c123】[]`、`拆[角色<诸葛连弩>]`、`选择<桃>`、`弃置<闪,杀>`、`展示<闪>`、`打出闪`、`结束出牌` 与稳定 `confirm/cancel`。隐藏手牌不能按曾经展示的牌面定向操作。
- 修复事件主体已 finished、End/After 循环仍在结算时的提前截断；不需要本人输入的被动结算和他人响应可继续等待。真正的本人新询问、目标失效或阶段变化仍会停止后缀。
- 保存 `play` 逐步收据，尾随观察失败仍返回已知进度；`receipt [ID]` 可离线读取历史收据。未知结果不自动重放。
- 随源码更新 noname-play 的滚动规划用法。

验证：本机配置匹配引擎后，602 项自动化测试全部通过。独立实玩样本中四步实体操作链跨过对手出闪继续完成；原生受控验证覆盖公开拆顺、弃牌、展示和响应。上一局人类对局恢复出 366 条实验事件，新一局后台采集已实际运行。

这是 Windows 实验版。整局读取指全部已保存的实验事件，仍保留 `experimental_partial` 标记；开局起点未验证，断线或缓存淘汰造成的缺失不能补回。完整人类观战从开局到关窗的独立验收尚未完成。连续 cancel 在来源动作变化时仍可能安全停下；任意第三方皮肤、任意技能组合与同页私有重置分局不作兼容承诺。2v2 已知停顿、官方版房间初始化及联机客机日志覆盖限制仍保留。

使用方法见 [观战与整局战报](SPECTATING.md)、[play](PLAY.md)；完整验证范围见 [VALIDATION.md](VALIDATION.md)。ZIP 不包含游戏本体、模型、本机配置、运行状态或原始实验日志。
