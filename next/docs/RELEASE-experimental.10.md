# 1.3.0-experimental.10

减少自动反馈中的重复全场状态；需要完整局面时主动 `observe`。

- 默认 `state=auto` 仅在自己每个真实出牌阶段的首次有效决策反馈中显示全场。
  同阶段后续反馈、自己的其他阶段和回合外响应隐藏概览；选择、revision、结果与战报保留。
- 普通 `observe` 和 `observe --json` 可随时重复查看全场，不再受自动隐藏限制。
  已保存的 show/hide 设置及单次显式覆盖继续生效。
- JSON 与文本共用展示记录；主动查看自己出牌阶段的有效决策也计入已展示。
  动作失败、过期快照与输出失败不消耗首次展示机会。
- 无法确认阶段或处于 setup/dead/over 时不自动附带全场，可用 `observe` 查看。

验证：613 项自动化测试全部通过，无失败或跳过。Luna（high）独立验收通过，
覆盖 19 项显示规则定向测试、独立 Node 探针及真实 CLI 入口的受控快照测试。
本次没有运行真实客户端整局对战，不扩大引擎或扩展兼容性声明。
既有测试房、联机和日志限制见 [验证范围](VALIDATION.md)。

详见 [场面显示规则](STATE-AUTO.md)。ZIP 包含示例与完整 noname-play Skill，
不包含游戏本体、本机配置、运行状态或原始对局记录。
