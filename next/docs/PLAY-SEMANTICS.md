# 白板 play 语义设计

2026-09-17 用户确认。实现入口为 `next/`；保留原 `act(...)` 与 `>` / `|` 行为。

## 范围

先支持实体牌使用、使用/打出响应牌、救援、弃牌、公开选牌、展示、普通锦囊后续选牌、装备交互、确认取消和结束出牌。武将技能选择、条件分支及循环不在本轮范围。

## 语法与匹配

| 表达 | 含义 |
| --- | --- |
| `杀` | 任意合法的杀，包括属性杀；目标未指定 |
| `火杀` / `雷杀` | 限定属性 |
| `杀【♥12】` / `杀【♥】` / `杀【12】` | 同时匹配写出的牌面条件 |
| `杀【id:c123】` | 实体身份精确匹配，并核对牌种；不是临时按钮 ID |
| `杀[丁真]` / `杀[fp5]` | 指定角色名称或身份 |
| `杀[]` | 明确授权任选一个合法角色目标；不包含敌我策略 |
| `拆[丁真<诸葛连弩>]` | 对丁真用过拆，并在关联询问中选择指定装备 |
| `拆[<诸葛连弩>]` | 联合匹配合法角色与公开卡牌对象，再固定一个组合 |
| `拆[丁真<任意>]` | 指定角色，明确授权任选其当前可选的牌 |
| `拆[丁真]` | 仅指定用牌目标；遇到后续选牌暂停 |
| `选择<桃【♥6】>` | 完成当前已绑定询问中的选牌 |
| `弃置<闪【♥12】,杀【♠7】>` | 选择这些牌并提交弃牌询问 |
| `展示<闪【♥12】>` | 选择指定牌并提交展示询问 |
| `打出杀【♣9】` | 在要求打出的询问中提交实体牌 |
| `结束出牌` | 结束当前正常出牌阶段，不取消别的询问 |
| `confirm` / `cancel` | 确认或取消当前已绑定交互；兼容 `act(confirm)` / `act(cancel)` |

`[]` 包含角色目标；角色后的 `<>` 包含针对该角色的卡牌对象；`【】` 限定牌面或实体身份。多角色目标仍用逗号分隔；独立选牌列表中的逗号表示不同实体牌。

省略牌面条件允许在匹配牌种内代选。省略角色括号不授权随机指定目标；规则决定的自身/全体目标仍由引擎处理。名称与日志共用简称；点数 A/J/Q/K 与 1/11/12/13 等价。角色名称消歧与实验日志一致，稳定 ID 保留为精确出口。

牌种、花色、点数、实体身份约束取交集。每步执行时从玩家安全投影中匹配并固定对象；固定后失效即停止，不换牌换人。隐蔽牌仅可按公开选项或明确的“任意”选择，不通过底层对象读取牌面。

## 执行与询问

预写的卡牌对象只属于本次用牌产生的关联询问，不可匹配其他插入询问。`拆[<诸葛连弩>]` 在提交之前联合检查角色和公开牌；引擎仍作最终合法性检查。

完整动作内部完成所需的选牌、目标和确认。已有选择被保留并核对；明确拒绝时只清理本步骤新增的选择。原始动作保留其原有语义。

确认/取消是稳定意图，当前可用性由原生控件和规则决定。可见但未收集的控件属于投影缺口；不把任何“取消”都解释为结束出牌。

调用入口严格核对 `--at`。单次调用内只允许在同一询问、相同选择与约束、相同操作对象的前提下跨过无关 revision 变化；发生过点击后结果未知不重放。阶段变化、换局、无关新询问继续停止。

这里的新询问指需要本玩家作出尚未承诺的选择。被动技能、其他角色之间的响应与选择，只要不需要本玩家输入，且后续动作仍合法，就在整体时限内等待后继续。已预写且正确绑定的后续选牌由工具完成。工具不根据日志内容替玩家重新制定策略。

原生事件的 `finished` 只表示主体结束，End/After 与后续事件仍可能运行。观察器已经见证、执行循环尚未返回的动作是 `pending`，不能因此归为提交结果未知。未见证的历史结束事件及真实执行异常仍为 `unknown`；等待超时保留已提交凭证与剩余串，不重放。

## 反馈

输出为简短步骤收据加执行期间的增量实验日志，不生成重复的战况摘要。收据显示实际选定对象，区分用牌已提交、后续选牌未完成、完整完成和结果未知。

尾随观察或反馈后处理失败不能丢弃已有收据。收据与日志事实分别保留；不能根据伤害有无判断用牌是否提交，也不能把连续日志行都归因于同一步。进程被外部终止时通过已保存的调用记录恢复可知进度，不承诺外部强杀后仍能输出 stdout。

## 验收场景

- 日志中的全部牌简称、属性杀、牌面和精确实体引用可用于匹配。
- 无目标、空目标、指定目标和多目标行为不同；代选不加入敌我偏好。
- 过拆/顺手固定目标与牌，跨动态按钮 ID；插入询问、被无懈、对象消失不误选不重放。
- 五谷选牌、弃多张、展示、实体响应及救援可提交；隐蔽信息不泄露。
- 原生确认/取消控件重建仍可操作；强制询问不会伪造取消能力。
- 同一交互无关刷新可以继续；已选对象、约束或询问身份变化必须暂停。
- 超时、尾随观察失败、日志或格式化错误返回已知收据；实验增量与原始流游标保持独立。
- 保留原完整用牌、原始操作、分组短路、联机用牌与日志回归。
